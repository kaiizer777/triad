# General Chat — Mini Skill

Continue answering the non-coding request directly and concisely. Keep the
response grounded in the conversation and ask only necessary clarifying
questions.

Lead with the useful conclusion, then include only the context needed to make
it understandable. Preserve relevant constraints and uncertainty from the
earlier exchange. Avoid proposing implementation, file edits, commands, or
external actions unless they are explicitly requested. For an ambiguous
question, ask a single focused question rather than making a risky guess.
